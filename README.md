# BlockBill

**BlockBill 0.4.2** — Fabric-мод для Minecraft Java Edition 26.3, в котором подписки задают правила прохождения. Добывай бесплатные ресурсы, продавай вещи за игровые кредиты и оплачивай доступ к шахте, спринту, мастерской и порталам. Всё управление находится во вкладке **E → BlockBill**: команды для прохождения не нужны. Реальных платежей, регистрации, внешней рекламы и телеметрии нет.

[HTML-инструкция установки](docs/install.html) · [Локальный JAR после сборки](build/libs/blockbill-0.4.2.jar) · [Результаты проверок](docs/PROGRESS.md) · [Контракт 0.4](docs/V04_CONTRACT.md)

Эта документация относится к локальной сборке 0.4.2. Ранее опубликованная версия — [0.3.1](https://github.com/Hasuk1/BlockBill/releases/tag/v0.3.1); в ней ещё нет нового игрового интерфейса и правил 0.4.

## Установка и обновление

| Компонент | Версия |
| --- | --- |
| Minecraft Java Edition | **26.3** |
| Fabric Loader | **0.20.1** |
| Fabric API | **0.165.0+26.3** |
| Java | **25 или новее**, сборка использует JDK 25 |
| BlockBill | **0.4.2** |

1. Установи и один раз запусти Minecraft Java Edition 26.3, затем закрой игру.
2. Установи [официальный Fabric Installer](https://fabricmc.net/use/installer/): Minecraft 26.3, Loader 0.20.1.
3. В папку `mods` выбранного Fabric-профиля положи `blockbill-0.4.2.jar` из комплекта или `build/libs` и [Fabric API 0.165.0+26.3](https://maven.fabricmc.net/net/fabricmc/fabric-api/fabric-api/0.165.0+26.3/fabric-api-0.165.0+26.3.jar). Не распаковывай JAR; `-sources.jar` не подходит.
4. Запусти профиль Fabric, создай мир выживания и открой **E → вкладка BlockBill** на краю окна инвентаря.

Стандартные папки: Windows — `%APPDATA%\.minecraft\mods`, macOS — `~/Library/Application Support/minecraft/mods`, Linux — `~/.minecraft/mods`. Если у профиля отдельная папка игры, используй её. На сервере и клиентах должны стоять одинаковые BlockBill и Fabric API. Bedrock, Forge и NeoForge не поддерживаются.

Перед обновлением закрой игру/сервер и сохрани копию всей папки мира. Замени прежний JAR на 0.4.2, оставив одну версию BlockBill. Старые балансы, оплаченные сроки и настройки сохраняются; trial не начинается заново. Travel+ не выдаётся задним числом. Для отката используй резервную копию мира.

## Всё управление в инвентаре

Вкладка **BlockBill** на краю окна раскрывает боковую панель мода. Обычные слоты и крафт Minecraft остаются видимыми рядом с ней. Вещи можно перемещать как обычно; отдельный режим выбора включается только в разделе продажи. Закрытие панели возвращает обычный вид инвентаря.

Внутри BlockBill доступны пять разделов:

| Раздел | Что можно сделать |
| --- | --- |
| **Обзор** | Увидеть баланс и доступ, купить отдельную услугу, включить или выключить её автопродление. |
| **Тарифы** | Сравнить и купить пакеты, Plus, Pro или Business. |
| **Продажа** | Нажать на реальный слот инвентаря, посмотреть цену в боковой панели и подтвердить продажу одного предмета или стека. «Все цены» открывает полный каталог с поиском по ID. |
| **Реклама** | Посмотреть выдуманную рекламу и получить 30 секунд всех услуг. |
| **Правила** | Прочитать все 15 разделов справки на русском или английском, листая страницы внутри панели. |

Кнопка **«Купить кредиты»** включает режим продажи: нажми на нужный предмет в обычном инвентаре, выбери количество и подтверди сумму в панели. В этом режиме клик выбирает вещь для продажи, а не берёт её на курсор. Сам выбор ничего не продаёт. Для обычного перемещения вещей перейди в другой раздел или закрой панель. Реальные деньги не используются. Интерфейс показывает результат сервера; повторный клик не должен повторно списывать предметы или выдавать награду.

## Free, пробный период и реклама

**Free доступен всегда:** обычная ходьба, поверхностные дерево и нерудный камень на Y40 и выше, базовый крафт, еда, бой, обычные сундуки, бочки и печи. Можно заработать на подписку без подписки. Для руды, глубокой шахты, спринта и других платных действий нужен доступ — trial, купленная услуга или рекламная награда.

Новый счёт получает **6000 активных тиков выживания**, около пяти минут всех 10 услуг. Выход или обновление мода не повторяет trial.

На вкладке **Реклама** нажми «Смотреть · 5 секунд», дождись отсчёта и нажми «Получить 30 секунд». Это 600 активных тиков доступа ко всем услугам. Следующая награда доступна через 1800 активных тиков (около 90 секунд) после получения предыдущей. Награды не складываются. Выход с вкладки или закрытие окна отменяет незавершённый просмотр. Никаких сайтов, видео из сети и реальных платежей. Реклама не покупает и не продлевает оплаченные услуги; их обычный отсчёт продолжается.

## Услуги и тарифы

| Услуга / ID | Цена за 10 минут | Без доступа |
| --- | ---: | --- |
| Mine+ (`mine`) | 20 | Нельзя ломать руду на любой высоте и любые блоки ниже Y40. |
| Sleep+ (`sleep`) | 15 | Нельзя заснуть и пропустить ночь. |
| Sprint+ (`sprint`) | 15 | Нельзя спринтовать; обычная ходьба доступна. |
| Enchant+ (`enchant`) | 25 | Нельзя открыть стол зачарования. |
| Anvil+ (`anvil`) | 20 | Нельзя открыть наковальню любого состояния. |
| Smith+ (`smith`) | 20 | Нельзя открыть кузнечный стол. |
| Trade+ (`trade`) | 20 | Нельзя начать торговлю со взрослым жителем или странствующим торговцем. |
| Fish+ (`fish`) | 15 | Нельзя забросить удочку; уже заброшенную можно смотать. |
| Storage+ (`storage`) | 15 | Нельзя открыть эндер-сундук или шалкеровый ящик. |
| Travel+ (`travel`) | 40 | Нельзя перейти порталом в Незер или Энд; возврат в обычный мир бесплатен. |

Руда включает ancient debris. Travel+ проверяет также пассажиров; для возврата в Overworld доступ не нужен. После оплаты у уже отклонённого портала может потребоваться выйти из него и зайти снова. Административные teleport-команды не ограничиваются.

| Тариф / ID | Состав | Минут каждой услуги | Цена |
| --- | --- | ---: | ---: |
| Базовый (`basic`) | Mine+, Sleep+, Sprint+ | 10 | 40 |
| Мастерская (`workshop`) | Enchant+, Anvil+, Smith+ | 10 | 50 |
| Исследователь (`explorer`) | Mine+, Sprint+, Fish+, Storage+ | 10 | 50 |
| All Access (`all`) | Все 10 услуг | 10 | 120 |
| Plus (`plus`) | Mine+, Sleep+, Sprint+, Fish+, Storage+ | 15 | 90 |
| Pro (`pro`) | Все 10 услуг | 30 | 300 |
| Business (`business`) | Все 10 услуг | 60 | 540 |

Цены указаны в игровых кредитах. Каждый тариф действует только на покупателя, включая Business. Покупка добавляет время каждой входящей услуге поверх её пробного или оплаченного остатка. Plus после Pro добавит 15 минут пяти услугам; остальные пять сохранят свой срок. Пакет покупается целиком или отклоняется без списания.

## Продажа и экономика

У каждого из **1657 ванильных предметов**, кроме пустого `air`, есть явная базовая цена. «Все цены» показывает полный каталог; поиск использует ID, например `diamond` или `minecraft:oak_log`. В продаже отображается цена конкретного состояния вещи. Кредиты учитываются до **0.01**.

| Предмет | Кредитов за штуку |
| --- | ---: |
| Обычное бревно | 0.75 |
| Камень / булыжник | 0.05 |
| Гнилая плоть / пшеница | 0.04 |
| Уголь | 0.25 |
| Медный слиток | 0.90 |
| Железный слиток | 2.25 |
| Золотой слиток | 4.50 |
| Редстоун | 0.20 |
| Изумруд | 2.50 |
| Алмаз | 20.00 |

Пример: собери 32 обычных бревна → **E → BlockBill → Купить кредиты** → нажми на стек в обычном инвентаре → «Продать стек» → подтверди **24.00 кредита** → **Обзор → Mine+** за 20 → останется **4.00**. Если брёвна лежат в нескольких слотах, продай каждый стек отдельно.

Износ снижает цену снаряжения. Имя и зачарования не создают наценку. Заполненный шалкер, мешок, заряженный арбалет или занятый улей сначала нужно освободить; содержимое не исчезает ради продажи. Неоткрытый loot-контейнер также защищён. Пустые контейнеры продаются. Продажа берёт только выбранный личный слот, не сундуки; устаревшая цена или изменившийся стек требуют обновления и нового подтверждения.

Предметам сторонних модов назначается консервативная цена 0.01; их особые схемы хранения не считаются проверенными. Цены учитывают количество выхода рецептов и дешёвые массовые ресурсы. Это проверяемая стартовая экономика, а не доказанный человеческим прохождением баланс. Подробнее: [MARKET_PRICING.md](docs/MARKET_PRICING.md).

## Автопродление, время и сохранения

В **Обзоре** переключатель «Авто» включает продление отдельной услуги; изначально всё выключено. Когда доступ закончится, сервер оплатит один период 10 минут по индивидуальной цене. Во время trial и рекламного доступа автоматического списания нет. При нехватке средств или невозможности продлить срок переключатель отключается до твоего ручного включения. Тарифы целиком автоматически не покупаются, ручная покупка не меняет переключатели.

При одновременном истечении порядок: mine → sleep → sprint → enchant → anvil → smith → trade → fish → storage → travel. Время и расходы идут только онлайн в survival. Офлайн, creative/spectator/adventure и настоящая пауза одиночного мира их останавливают. **Инвентарь, панель BlockBill и чтение правил не ставят игру на паузу**: часы подписок продолжают идти. При низком TPS секунды растягиваются.

Баланс с дробной частью, сроки, рекламный cooldown и настройки сохраняются после смерти, выхода и перезапуска. Чужие эффекты зелий не удаляются. Новая версия не накладывает усталость или замедление; старые короткие эффекты 0.3 завершаются сами. Открытое меню станции не закрывается при истечении услуги. Обычная кровать сохраняет ванильную установку точки возрождения без Sleep+; соломенная кровать следует своим ванильным правилам.

## Необязательные команды

```text
/blockbill help
/blockbill services
/blockbill plans
/blockbill status
/blockbill prices
/blockbill buy <услуга, пакет или тариф>
/blockbill autorenew <услуга> on
/blockbill autorenew <услуга> off
/blockbill exchange <ресурс> <число наборов>
```

Старый `exchange` сохранён для совместимости и использует те же новые цены предметов, что UI. Прежние завышенные курсы 0.3 больше не действуют. Операторская `/blockbill debug credits <amount>` не нужна обычному игроку.

## Разработка и проверки

```sh
./gradlew clean test build
./gradlew runGameTest
./gradlew runClientGameTest
./gradlew runClient
```

Нужен JDK 25; на Windows — `gradlew.bat`. Запуски Gradle выполняй последовательно. Итоговый мод: `build/libs/blockbill-0.4.2.jar`. GameTests используют отдельный тестовый мир с dev-настройкой `eula = true`; `runClientGameTest` запускает настоящий клиент автоматических проверок, `runClient` — ручную игру. Фактические результаты и ограничения текущей сборки: [PROGRESS.md](docs/PROGRESS.md). Успешная сборка не заменяет игровой плейтест.
