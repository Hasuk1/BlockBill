# Верифицированные отправные точки для агента (27.10.2026)

Внимание: это ссылки для **первой проверки**, а не гарантия совместимости конкретных зависимостей спустя время. Перепроверь актуальные версии и API непосредственно перед сборкой.

- Minecraft Java Edition 26.3 (официальный релиз 15.09.2026): https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3
- Fabric: заметки о поддержке и изменениях Minecraft 26.3: https://fabricmc.net/2026/09/15/263.html
- Fabric: текущие версии инструментов для выбранной версии Minecraft: https://fabricmc.net/develop/
- Официальный генератор/инструкция нового проекта: https://docs.fabricmc.net/develop/getting-started/creating-a-project
- Настройка JDK 25: https://docs.fabricmc.net/develop/getting-started/setting-up
- Fabric Loom / plugin IDs для новых необфусцированных версий: https://docs.fabricmc.net/develop/loom/
- Fabric Events (проверить события именно в целевой версии): https://docs.fabricmc.net/develop/events/
- Команды Fabric: https://docs.fabricmc.net/develop/commands/basics
- Saved Data: https://docs.fabricmc.net/develop/serialization/saved-data
- Data Attachments: https://docs.fabricmc.net/develop/serialization/data-attachments

**Особенность:** некоторые страницы docs.fabricmc.net на момент подготовки показывают руководство 26.2. Агент не должен слепо переносить сигнатуры в 26.3: надо подтвердить компиляцией против целевых зависимостей. Страница fabricmc.net/develop/ может меняться динамически; выбор Loom должен основываться на совместимом шаблоне и сборке.
