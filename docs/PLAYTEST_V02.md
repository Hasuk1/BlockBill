# Плейтест 0.2.0

Автоматические проверки подтверждают правила и сохранение. Для оценки удобства нужен отдельный человеческий сеанс; стартовые цены пока не менялись по результатам такого сеанса.

1. После trial заработать на Basic, затем отдельно выбрать Workshop или Explorer. Проверить, понятен ли выбор между девятью услугами.
2. Сравнить доход от дерева, руды, фермы пшеницы, боёв и обмена изумрудов. Проверить, не делает ли один ресурс остальные бессмысленными.
3. Проверить ограничения наковальни, зачарования, кузнечного стола, жителей, удочки и переносных хранилищ в обычном прохождении. Убедиться, что цена и команда отказа понятны без документации.
4. Включить одну услугу на автопродление; затем несколько при ограниченном балансе. Оценить понятность очередности, уведомления о списании и выключения при нехватке денег.
5. Проверить движение, бесплатный крафт, сундуки, лечение жителей и выход из трудной ситуации без подписок. Открытый интерфейс не должен выбрасывать предметы, удочка должна сматываться после expiry.

Три гипотезы баланса: доход зрелых ферм может обесценить All Access; десятиминутный срок девяти услуг может требовать слишком много управления; сумма индивидуального автопродления (165) заметно выше пакета All Access (120). Это осознанные стартовые правила, которые нужно оценить игрой, а не незаметно менять автоматически.
