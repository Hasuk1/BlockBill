# BlockBill 0.4: цены рынка

Это стартовая экономика, а не доказанный игровой баланс. Один кредит равен 100 центам. Цена относится к одному предмету; итог стека рассчитывается сервером. Встроенный JSON содержит **1657 явных положительных цен** для всех предметов реестра Minecraft Java 26.3, кроме `air`. При старте `ItemPriceCatalog.validateRegistry()` сравнивает таблицу с настоящим реестром и отклоняет несовместимую версию.

## Основа цен

| Предмет | Цена одного предмета |
| --- | ---: |
| Бревно дуба, берёзы, ели и обычных пород | 0.75 кредита |
| Дубовая доска | 0.18 |
| Обычный камень / булыжник | 0.05 |
| Бамбук / сахарный тростник | 0.02 |
| Гнилая плоть / пшеница | 0.04 |
| Уголь | 0.25 |
| Медный слиток | 0.90 |
| Железный слиток | 2.25 |
| Золотой слиток | 4.50 |
| Красная пыль | 0.20 |
| Изумруд | 2.50 |
| Алмаз | 20.00 |

Массовая земля, растения и дроп фермы стоят мало. Редкая добыча стоит больше. Для природных предметов задана проверяемая категория, для изготовленных цена ограничена самым дешёвым вариантом ванильного рецепта. Неизвестная категория останавливает генератор; скрытого общего значения для vanilla нет. Creative/admin-предметы имеют явную символическую цену 0.01, но игрок в creative продавать не может.

Алгоритм учитывает количество выхода, альтернативные ингредиенты и item tags. Цена результата не превышает стоимость расходуемых ингредиентов. Возвращаемые вёдра и стеклянные бутылочки вычитаются из стоимости рецепта. Обратимые крафты сохраняют стоимость: девять самородков равны слитку, девять слитков — блоку. Четыре дубовые доски стоят не больше одного бревна. Раскраска, зачарование и имя не добавляют наценку.

Проверка включает **2100 ограничений**: рецепты из точного Minecraft JAR и явные превращения в мире — зачистку древесины, окисление меди, затвердевание бетона. Рецепты, меняющие только компоненты предмета, перечислены отдельно в отчёте генератора. Код не даёт наценки за компоненты. Починка меняет оставшуюся долговечность: её бонус и затраты опыта требуют отдельной игровой оценки; проверки базовых рецептов не объявляются доказательством баланса ремонта, торговли жителей, ферм, datapacks или сторонних модов.

## Состояние предмета и защита вложений

Изношенное снаряжение получает линейную скидку: `floor(базовая цена × оставшаяся прочность / максимальная прочность)`, минимум 0.01 кредита. Количество предметов в стеке не меняет цену единицы. Встроенные зачарования и пользовательское название не повышают цену.

Предмет с непустым `ContainerComponent` нельзя продать: это включает шалкеры, мешки и заряженные арбалеты. Сначала нужно освободить содержимое или разрядить оружие. Занятые ульи и ещё не раскрытый loot контейнера также защищены. Проверка не изменяет стек, вложения или пчёл. Пустой контейнер продаётся по своей базовой цене.

Неизвестный предмет другого мода получает консервативную цену 0.01 кредита с однократным предупреждением в журнале. Обычные компоненты контейнеров защищены и у него. Произвольные собственные схемы хранения вложений сторонних модов не считаются проверенными.

## Воспроизведение

`vanilla-items.json` — список `BuiltInRegistries.ITEM` из отдельно запущенного vanilla 26.3 Bootstrap. При подготовке версии использован `.local/research/vanilla-items.json`, созданный основным агентом. Нельзя заменять его случайным списком из сторонней версии. Runtime GameTest независимо сравнивает полученный JSON с полным реестром.

```sh
python3 scripts/generate_market_prices.py \
  --registry .local/research/vanilla-items.json \
  --minecraft-jar /path/to/exact-26.3/minecraft-client.jar
```

Скрипт не запускает Minecraft, не использует сеть и не меняет миры. Он записывает:

- `src/main/resources/assets/blockbill/item_prices.json` — полный каталог для мода.
- `src/test/resources/market/recipe_constraints.json` — проверяемые ограничения рецептов.
- `.local/research/market-price-report.json` — категории каждого предмета, SHA-256 исходного JAR, число итераций и список специальных рецептов.

Для текущего каталога выполнены 22 итерации уменьшения цен; необработанных типов/результатов рецептов нет. Unit-тест независимо проверяет ограничения через `BigInteger`. GameTests проверяют полный реестр, долговечность, отсутствие наценки за имя и сохранность вложений. Итоговые результаты запуска фиксирует основной отчёт проверки; сам факт наличия тестов не означает успешный прогон.
