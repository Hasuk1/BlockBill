# Проверка BlockBill 0.4.1 — 28 октября 2026

Исправлен интерфейс по уточнению владельца: обычный инвентарь остаётся видимым слева, BlockBill открывается боковой панелью справа. Исходный InventoryScreen/CreativeModeInventoryScreen и серверное меню сохраняются. «Купить кредиты» включает продажу: клик по реальному слоту выбирает вещь, зелёная рамка отмечает выбор, в панели показана сумма и подтверждение. Перенос предметов вне режима продажи работает как в vanilla. Книга рецептов временно закрывается и восстанавливается после закрытия панели. Все 15 разделов правил встроены в панель.

## Результаты

| Проверка | Результат |
| --- | --- |
| `./gradlew build` | **Успешно**, 92 unit-теста и 54 серверных GameTest. |
| `./gradlew runClientGameTest` | **Успешно**, настоящий Minecraft-клиент с одиночным миром; 45 скриншотов. |
| `./gradlew productionServerSmoke -PrestartPhase=read` | **Успешно**, dedicated JVM PID 37813 загрузила новый JAR и сохранённые в 0.4.0 счета без изменений. |
| Упаковка | Проверка локальных HTML-ссылок, состава JAR, ZIP CRC и SHA-256 каждого файла выполняется `scripts/package_release.py`. |

Клиентский сценарий проверяет неизменность объекта Screen/menu, настоящее поднятие и размещение стека, курсор при клике по отключённой вкладке, открытие/закрытие книги рецептов, обычные переносы при открытой панели и выбор настоящего слота в продаже без преждевременного расхода. Проверены продажа одной вещи и стека с точным начислением, поиск каталога по нескольким страницам, Mine+/Pro, автопродление, отмена рекламы и полный просмотр с наградой. RU/EN, все разделы правил, размер GUI320×240, сохранение раздела после resize, survival/creative, Escape и возврат также прошли.

В ходе реального ввода обнаружены и исправлены два случая: отключённая вкладка могла пропускать клик в ванильное выбрасывание стека; быстрый «слот → вкладка → слот» мог считаться double-click и собирать стек вместо размещения. Финальный тест проверяет быстрый сценарий без задержки между вкладкой и размещением. Два обычных последовательных клика по одному слоту, напротив, сохраняют ванильный double-click.

Ванильная отрисовка не отменяется. Панель рисуется через Fabric afterForeground; подсказки остаются поверх неё. Используются только два узких клиентских accessor Mixin для геометрии, книги рецептов и lastClickSlot. Удалён старый отдельный полноэкранный экран справки.
