# BlockBill 0.3.1

Первый публичный выпуск: девять услуг, четыре пакета, тарифы Plus / Pro / Business, десять обменов ресурсов и добровольное автопродление. Minecraft Java 26.3, Fabric Loader 0.20.1, Fabric API 0.165.0+26.3, Java 25.

## Исправления после 0.3.0

- Повреждённое сохранение счетов больше не превращается в пустую или частично загруженную таблицу. Загрузка останавливается с указанием файла; исходные байты сохраняются. Это предотвращает потерю баланса и повторную выдачу trial. Нужно восстановить корректную резервную копию мира, а не удалять файл счетов.
- Изменение размера окна справки сохраняет текущий раздел и ближайшую доступную подстраницу.
- Актуализированы инструкция установки, игровые правила и техническая спецификация; добавлены воспроизводимая упаковка и автоматические проверки на GitHub.

## Воспроизведение и выпуск

```sh
./gradlew clean test build runClientGameTest
./gradlew productionServerSmoke -PrestartPhase=write
./gradlew productionServerSmoke -PrestartPhase=read
python3 scripts/package_release.py
```

Production smoke запускает две отдельные JVM с построенным игровым JAR и отдельным тестовым модом. В игровой JAR тесты не входят. Мир по умолчанию находится в `.local/production-smoke-v031`; для независимого тестового мира используется `-PsmokeRunDir=<path>`. Успех подтверждают JSON-файлы после штатного сохранения и остановки сервера, а не только код возврата процесса.

На GitHub настроены сборка/JUnit/server GameTests на Linux и Windows, а также настоящий клиент под виртуальным дисплеем Linux. Результаты конкретного опубликованного коммита доступны в [Actions](https://github.com/Hasuk1/BlockBill/actions/workflows/verify.yml); итоговый статус CI приводится в описании релиза.

Скрипт упаковки проверяет версии, локализации, состав JAR, HTML-ссылки, целостность ZIP и контрольные суммы каждого файла. Выпуск содержит игровой JAR, ZIP с автономной HTML-инструкцией и документацией, отдельный HTML и SHA256SUMS. Fabric API устанавливается отдельно. В комплект не входят игровые миры, логи, локальные настройки или секреты.

## Ограничения

Автоматические проверки не заменяют человеческий плейтест экономики и полное прохождение до дракона. Совместимость с произвольными сторонними модпаками и внешний публичный многопользовательский сервер не проверены. Business действует только на покупателя. Существующие эффекты замедления могут завершить свой короткий TTL после оплаты; чужие эффекты мод не удаляет.
