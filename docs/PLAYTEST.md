# Ручной плейтест BlockBill 0.1.0

Автоматические игровые проверки завершены; этот лист предназначен для оценки удобства и баланса человеком. Изменять цены по непроверенным предположениям не стали.

## Маршрут на 15–25 минут

1. Новый survival-мир, без выдачи кредитов через debug. Открыть правила из инвентаря, проверить читаемость и понятность команд.
2. Собрать 32 бревна за trial, обменять два набора. Купить Mine+, убедиться, что срок прибавился к оставшемуся trial.
3. Дождаться конца trial. Проверить шахту ниже Y40, непрерывный спринт и сон; заработать кредиты без оплаченных услуг.
4. Купить Sleep+, поспать; купить Sprint+, пробежать; накопить на All Access. Отметить, были ли осмысленные решения между услугами.
5. Умереть, перейти в Nether, выйти и открыть мир снова. Сравнить баланс и сроки командой status.
6. Отметить лишние уведомления, непонятные отказы, обходы оплаты и неудобное размещение кнопки справки.

Записывать время до первой покупки, ресурсы/кредиты на каждом этапе, число отказов и периоды, когда можно бесконечно продлевать всё без выбора. Для полного прохождения отдельно проверить End/дракона.

## Гипотезы для следующей версии

1. **Цена поздней игры.** Автоматические фермы дерева/железа могут сделать All Access почти бесплатным. Проверить обычное прохождение и ферму; не вводить dynamic pricing без отдельного согласования.
2. **Порог первой покупки.** 16 брёвен дают 12 кредитов, Mine+ стоит 20. В справке указан пример с 32 брёвнами; проверить, хватает ли новичку trial для понимания и накопления.
3. **Частота ручного продления.** Десятиминутные периоды могут отвлекать от исследования. Проверить 15–25 минут игры и частоту команд; автопродление остаётся вне текущего MVP.

Это открытые вопросы, а не измеренные проблемы и не основание менять согласованные правила автоматически.
