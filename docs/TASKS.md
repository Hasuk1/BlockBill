## Definition of Done
1. Команда Gradle build успешна.
2. Доменная логика покрыта тестами; результат указан.
3. Обмен и покупки атомарны.
4. Состояние переживает выход, смерть и рестарт мира.
5. Никаких необратимых softlock и бесконечного chat-spam.
6. `AGENTS.md`, game design и команды актуальны.
7. Реализованы только заранее утверждённые функции MVP.
