# BlockBill 0.4 — инвентарь, рынок, Free и новые правила

Этот запрос владельца заменяет прежнюю идею мягких неудобств. Уточнение 0.4.1: BlockBill открывает боковую панель рядом с обычными видимыми слотами, сохраняя исходный InventoryScreen/CreativeModeInventoryScreen и меню. Крафт и перенос предметов доступны рядом с модом. «Купить кредиты» включает режим продажи: клик по реальному слоту выбирает предмет без переноса, цена и подтверждение находятся в боковой панели. Предмет на курсоре нужно положить в слот перед открытием панели. Книга рецептов временно закрывается, а после закрытия панели её состояние восстанавливается. Полная справка также встроена в панель; интерфейс и справка не ставят мир на паузу. Команды остаются необязательным дополнительным входом, но не нужны для прохождения.

Free действует всегда: поверхность, дерево/обычный камень, базовый крафт, еда, бой, обычные сундуки и возможность заработать. Mine+ запрещает ломать руду (включая ancient debris) и блоки ниже Y40 без доступа. Sprint+ запрещает спринт. Остальные семь прежних правил сохраняют жёсткие запреты открытия/использования; новых штрафных эффектов больше нет. Travel+ (40 кредитов/10 минут) требуется для перехода порталами в Nether/End, в том числе пассажирам; возврат в Overworld свободен. Административные teleport-команды не являются обходом игрового UI и остаются административными. Всего десять услуг. All/Pro/Business включают десять; состав остальных пакетов и цены не меняются. Старые сохранения не получают Travel задним числом.

Trial остаётся 6000 online survival-тиков для совместимости. Все paid/trial/ad сроки считают те же активные тики, офлайн/creative/spectator/adventure время и расходы остановлены. Старые эффекты от 0.3 завершают короткий TTL; чужие эффекты не удаляются.

Реклама полностью выдуманная, без сети/реальных денег/телеметрии. Нажать «Смотреть» → пять секунд серверного отсчёта в открытом UI → «Получить 30 секунд». Награда даёт 600 активных тиков всем услугам, не суммируется с другой рекламой и не тратит/изменяет оплаченные сроки. Следующая награда не раньше 1800 активных тиков после предыдущей. Закрытие/выход отменяют незавершённый просмотр; повтор запроса не выдаёт повторную награду. Срок и cooldown сохраняются.

Кнопка «Купить кредиты» открывает продажу предметов; никаких платежей. Для каждого зарегистрированного vanilla item, кроме AIR (не предмет инвентаря), есть явная цена в JSON. Денежная точность — 0.01 кредита; прежние целые балансы остаются неизменными, дробная часть хранится отдельно. Показывать итог перед подтверждением продажи одного предмета или стека. Долговечность снижает цену, enchant/custom name не создают стоимость из воздуха. Заполненные контейнеры/бандлы/заряженные предметы нужно сначала освободить, чтобы вложения не исчезали при продаже.

Операции серверные. Quote содержит revision и копии текущих стеков: продажа по устаревшему snapshot, неверному слоту/количеству или сменившимся компонентам отклоняется целиком. Клиент не задаёт цену, баланс, UUID или срок. Перед списанием проверить будущий баланс и количество; после успешной продажи синхронизировать inventory и UI. Все команды продажи используют ту же экономику; старые фиксированные обмены не должны оставлять завышенный обход нового рынка.

Цены — воспроизводимая стартовая экономика: низкая стоимость массовых/автоматизируемых ресурсов, больше за редкую добычу; обратимые крафты и количество выхода учитываются. Тесты обязаны доказать полное покрытие registry, точную арифметику, границы/overflow и отсутствие очевидного умножения стоимости крафтом. Честный баланс в обычной игре не объявлять доказанным без плейтеста.

## Сетевой UI-контракт

`HubRequest(String action, String value, int slot, int amount, long revision)` и `HubState(String json)`, ids blockbill:hub_request/state. Request actions: OPEN, REFRESH, CLOSE, BUY (value=service/bundle id), AUTO (value=service id,amount=1/0), SELL(slot,amount,revision), AD_START, AD_CLAIM, AD_CANCEL, CATALOG(slot=page,value=search). Fields bounded; server validates and throttles.

State JSON:
```
{revision:long,balance:string,survival:boolean,trialTicks:long,adTicks:long,
 adCooldownTicks:long,adWatchTicks:int,adWatching:boolean,message:string,
 services:[{id,price:long,remainingTicks:long,autoRenew:boolean,access:boolean}],
 plans:[{id,price:long,minutes:long,services:[string]}],
 inventory:[{slot:int,item:string,count:int,unitPriceCents:long,blocked:string}],
 catalog:[{item:string,unitPriceCents:long}],catalogPage:int,catalogPages:int,catalogSearch:string}
```
`message` и `blocked` — ключи локализации (пусто при отсутствии). Каталог по 45 позиций, поиск по registry ID; порядок стабильный. Снимок по OPEN/REFRESH и после действий, heartbeat REFRESH раз в20 клиентских тиков пока экран открыт. Ads: adWatchTicks=сколько ещё ждать из100, adWatching=true даже после завершения ожидания до CLAIM. CLOSE отменяет просмотр. REFRESH не меняет revision, если инвентарь неизменён; каждый SELL/новый quote меняет его. Все mutation requests несут revision, чтобы повторная доставка BUY/AUTO/SELL/AD_CLAIM не тратила/не награждала дважды; REFRESH/CATALOG/AD_CANCEL/CLOSE не требуют revision.

Дополнительный `AccessState(int mask)` клиентbound передаёт доступ по ordinal ServiceType каждые20 серверных тиков при изменении. Клиент выключает предсказание спринта, если Sprint запрещён; сервер всё равно проверяет самостоятельно. Никаких client prices/state принимаемых за истину.
