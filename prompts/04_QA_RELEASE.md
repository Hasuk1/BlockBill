# PROMPT 04 — QA, БАЛАНС И АРТЕФАКТ СБОРКИ

Выполни аудит текущей реализации BlockBill по `AGENTS.md`, `docs/GAME_DESIGN.md`, `docs/TECH_SPEC.md` и `docs/TASKS.md`.

1. Сверь реализации каждого правила с GDD, оцени риски обхода оплаты, ошибки списаний и softlock.
2. Выполни `./gradlew clean test build` и отчитайся о точном результате. Если возможно, запусти `runClient` и проверь поведение в новом survival-мире (не считай один только Gradle build ручным тестированием).
3. Проверь последовательность: trial → истечение → сдача логов → покупка Mine+ → продление → Sleep+ и Sprint+ → All Access → смерть → выход → перезапуск мира.
4. Проверь работу с разными породами брёвен, пустым инвентарём, повторной покупкой, большой величиной `bundles`, creative и spectator.
5. Проверь сообщения и локализации, исключи chat-spam и резкие беспричинные наказания.
6. Подготовь в README точные шаги для локальной установки собранного `.jar` и совместимых Fabric Loader/Fabric API.
7. Назови конкретное местоположение jar в `build/libs/`, не выдумывай имя файла. Не публикуй файл без явного запроса.
8. Составь краткий отчёт о реально проверенных и непроверенных сценариях, 3 главных проблемах баланса и возможных улучшениях для следующей версии. Открой задачи, а не реализуй новые фичи.
