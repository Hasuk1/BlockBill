# PROMPT 01 — НАЧАЛО / BOOTSTRAP (скопировать в Codex первым)

Ты работаешь в локальном репозитории Minecraft Fabric-мода BlockBill. Прочитай `AGENTS.md`, `README.md`, `docs/GAME_DESIGN.md`, `docs/TECH_SPEC.md`, `docs/TASKS.md`, `docs/RESEARCH_SOURCES.md` целиком. Это спецификация проекта. Не предлагай новую идею и не переписывай игровой дизайн по своему усмотрению.

**Задача этого запуска — подготовить компилируемый Minecraft 26.3 Fabric-проект и подтвердить техническую осуществимость MVP, не пытаясь сразу реализовать всё.**

1. Проверь окружение: Java 25, Gradle Wrapper, доступ к Gradle и Minecraft dependency repositories. Сверь официальные версии Loader/API/Loom/Gradle и инструкции для необфусцированного Minecraft 26.3. Не копируй устаревшие Yarn-примеры.
2. Создай базовый проект из официального Fabric template (либо вручную в соответствии с официальным шаблоном), с modid `blockbill`, package `dev.blockbill`, основным entrypoint `BlockBillMod`. **Не удаляй существующие документацию и инструкции.**
3. Сделай минимальную реальную загрузку мода, нейтральное server-side логирование и нужные `fabric.mod.json` + Gradle файлы. Никакого собственного UI/предметов/мобов.
4. Исследуй доступные хуки Fabric для: применения Mining Fatigue, ограничения сна при клике на кровать (включая новую Straw Bed), отслеживания спринта, команд и сохранения состояния. Для каждого укажи конкретную проверенную API точку или риск. Предпочитай Events, не делай Mixins без необходимости.
5. Обнови `docs/TECH_SPEC.md` (фактические версии и хуки) и отмечай пункты этапа 0 в `docs/TASKS.md` **только после выполнения**.
6. Запусти `./gradlew build`; если окружение не даёт скачать зависимости, зафиксируй точную ошибку и понятную инструкцию воспроизведения. Не утверждай, что сборка успешна без выполнения команды.

Держи scope небольшим. Не переходи к полной экономике, Sleep+ и Sprint+ в этом запуске. В конце отчитайся: что создано, какие версии закреплены, что проверено командой, есть ли блокеры, следующий шаг — vertical slice Mine+.
